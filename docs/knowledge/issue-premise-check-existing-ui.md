# Issueの前提は実画面で確かめてから起票する

## 何が起きたか

- Issue #25 は「お題と生成中の表示がホスト以外に見えない」を前提に起票した
- 実装に入ると、お題も生成中の表示も既に全員へ出ていた。重複する行を足してから気付き、削除してPR本文に前提違いを書いた
- 起票後のIssue本文の検証でも、既存の`isFlooding`や行番号の誤りが見つかった

## なぜ

- コードを読んだだけで「見えないはず」と判断し、2クライアントで実際に画面を開いていなかった

## どうするか

- 表示や共有に関するIssueは、起票前にホストとゲストの2クライアントを開いて現状を見る (`scripts/e2e/`のスクリプトで撮れる)
- Issue本文の事実の主張 (既存の関数・行番号・現在の挙動) は、起票前に別agentで検証する
