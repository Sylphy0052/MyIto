# ito online

協力型カードゲーム「ito」をブラウザで遊ぶためのWebアプリ。会話は通話で行い、アプリはカードの配布、例えの記入、並べ替え、公開を担う。

## 遊び方

1. ニックネームを入れて「ルームを作る」。作った人がホストになる
2. ヘッダの「招待URLをコピー」で他の参加者を呼ぶ (4文字のルームコードでも入れる)
3. ホストがモード、1人あたりの枚数、お題 (ランダム / 自由入力 / AI生成) を決めて開始する
4. 自分の数字は画面上部に常に表示される。自分のカードに例えを書くと全員に見える
   - 協力: 小さいと思う人から「出す」。場より小さいカードが残っていたらミスとして公開される
   - 自由配置: 列をドラッグか矢印で並べ替え、ホストが「オープン」すると左から順にめくれる

リロードしても同じ席に戻る。サーバを再起動すると全ルームが消える。

## 開発

```sh
npm install
npm run build && npm start   # http://localhost:47213
# または npm run dev:server と npm run dev:client を別々に起動 (http://localhost:5173)
```

## デプロイ

```sh
# AIお題を使うなら、手元で `claude setup-token` を実行してトークンを作り、
# CLAUDE_CODE_OAUTH_TOKEN=... を書いた .env を compose.yaml と同じディレクトリに置く
# (任意。無ければAI生成は内蔵リストへフォールバック。ANTHROPIC_API_KEY でも動く)
docker compose up -d --build
```
